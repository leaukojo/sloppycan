Notch workflow
Click Notch to listen for a moment - every byte that changed gets marked noisy (amber), the rest stable (grey). Then wiggle a control: the byte that reacts lights up green, so you can pin down which byte a button or pedal drives.
Graph
Right-click an ID List row to graph one of its bytes. On the graph, drag to pan and use the wheel to zoom.
ID List vs Traffic Dump
ID List shows one row per CAN ID with its latest payload - best for spotting which bytes change. Traffic Dump is the raw, time-ordered log of every frame - best for following sequences and exporting.
